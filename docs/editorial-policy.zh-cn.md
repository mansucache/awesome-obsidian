# 编辑规范

## 写什么

每条资源默认一句具体用途，名称直接链接原始来源。介绍回答「能做什么」，尽量自然带出使用场景。收费资源用简短标识，主题配图。避免夸张排名和重复的推荐套话。

工作流可展开步骤与完成判据；普通插件、模板或工具不要求长文。信息不足时减少结论，不补宣传词。

## 来源与双语

核对原始资料，中文与英文保持同一含义。来源和维护信息放在数据记录里，不把执行过程、审核进度或验证声明展示给读者。

图片来源、作者与许可集中在 assets/README.md，保留相应许可原文。正文与图注只帮助读者认识资源。

## 维护与利益关系

收费资源和作者自荐可以收录，付费不购买排名或收录资格。维护者自己的资源披露关联。新增、纠错和失效反馈按来源判断，不仅凭热度。

README 和网站由同一来源生成。修改之后检查双语、链接和图片，不分别维护重复介绍。
