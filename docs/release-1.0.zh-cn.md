## 阅读与维护

英文 README 为默认入口，中文 README 提供完整对应内容，两者均包含全部条目与主题图片。普通资源用名称、原始链接和一句用途介绍；场景指南提供步骤与完成判据。资源数据、双语正文与导航共同生成 README 和网站，避免维护两份目录。

站点采用 Python 标准库生成静态文件，无需安装第三方依赖。1.0 保留经过校验的有限 Markdown 语法：一二级标题、段落、无序列表和链接；图片由资源数据生成。复杂排版需求出现后再考虑更换渲染器。

## 构建

需要 Python 3.10 或更高版本。在仓库根目录运行：

```sh
python3 scripts/catalog.py check --release
python3 -m unittest discover -s scripts -p 'test_*.py'
python3 scripts/catalog.py build --release
python3 -m http.server 18765 --bind 127.0.0.1 --directory site/dist
```

打开 http://127.0.0.1:18765/ 。英文为默认语言，中文入口在页面导航中。`site/dist` 可交给支持静态文件的托管服务，资源使用相对路径；发布前确定托管地址即可。构建会重建输出目录，不在其中手工保存内容。日常预览使用不带 `--release` 的构建命令，输出到 `site/preview`。

## 维护方式

新增资源先查重，再维护资源记录、双语正文和用途分组。价格、项目迁移、归档与失效链接优先处理；每次改动运行检查并重建 README。GitHub 工作流在推送或 PR 时执行同样的校验、测试和构建，并检查生成内容是否同步。
