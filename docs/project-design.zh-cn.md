# Awesome Obsidian 项目设计

决策日期：2026-10-07。用户已确认定位、内容边界、样本实施与后续内容扩充；公开发布尚未执行。

## 定位与语言

面向全球用户的 Obsidian 生态指南。资源分类为主入口，场景串起工具组合；全面覆盖领域，精选具体条目，并逐步积累基础索引。

设计讨论和当前审核以中文进行。正式网站与根 README 以英文为主，提供中文入口；README 自身提供完整分类、一句话资源介绍、必要收费标识与主题图片，读者无需网站也能阅读。原始空框架留档于 docs/archive/initial-readme.md。贡献者可以直接提交英文，不必先写中文。

重点服务已在使用 Obsidian、需要选择资源和改善流程的人，兼顾新手起步。仓库保留 awesome-obsidian，英文展示名 Awesome Obsidian，中文名「Obsidian 生态指南」。标明社区项目，不暗示官方背书。

## 信息体验

README 与仓库内 Markdown 是独立可用的交付，不是网站宣传页。英文 README.md 与中文 README.zh-CN.md 均包含目录、全部当前条目的一句话用途、原始链接、必要收费标识与主题图片；长篇内容通过相对链接在仓库内继续阅读。网站仅增强搜索、筛选、图库和移动浏览，不独占关键说明。

验收时先检查 GitHub/普通 Markdown 阅读路径，再检查网站增强体验。下载仓库后，不启动服务、不构建网站也能阅读已有文档和本地图片。

1.0 首页提供任务入口、分类导航、搜索筛选和主题图库；版本变化记录在 CHANGELOG，不制造精选排名或新增历史。

分类页支持费用、平台、场景等适用筛选。普通条目使用「名称＋原始链接＋一句具体用途」，不为每条资源写长篇。工作流等确有展开价值的内容独立成文。主题有图、插件有场景；图片署名与许可集中到来源文件。替代资源没有正式收录时可链接原始来源，但不得制造不存在的内部条目。

场景指南：具体目标 → 内置功能能做到哪里 → 最小组合 → 操作 → 可核对结果 → 限制 → 可选进阶。优先从少装插件的可行方案起步。

## 双语与内容架构

`data/resources/<id>.json` 保存共享事实；`content/en/<id>.md` 和 `content/zh-cn/<id>.md` 保存原创说明。稳定英文 ID 用于关联和地址，标题改变不改变身份。

`revision` 是整条记录的事实/内容修订号；每个语言记录自己的 `based_on_revision` 和正文 SHA-256。字段或任何正文有实质变化时先提升 revision，受影响译文标记 stale；两种语言重新审核后才置为 current。校验只发现不同步，不代替翻译审核。

英文默认入口，语言切换保留当前条目。未来缺译需显式说明回退，首批样本要求双语齐全。标签及平台的机器 ID 稳定，显示名称本地化。内部维护信息不出现在读者正文中。

## 技术决策

1.0 使用 Python 标准库生成静态网站，保留英文与中文路由、搜索、筛选及手机布局。当前内容结构无需引入前端框架；更复杂的页面需求出现后再评估 Astro。

生成器只接受约定的 Markdown 子集，遇到未支持语法会报错；发布构建与日常预览分别输出到 site/dist 和 site/preview，详见 [1.0 内容版](release-1.0.zh-cn.md)。

生成数据来自同一份事实及正文，英文/中文目录也自动生成。README 的人工介绍保留在生成区域外，分类正文由共享数据和双语正文生成；原始草稿另行原样留档。首版不做账户、评论、数据库、自动全量目录镜像或可下载完整 Vault。

## 可信度与治理

内部记录收录依据与来源，读者目录直接展示用途，不设星级总分。付费资源和作者自荐允许，买排名、买收录和首版返佣不允许。自己的资源披露关联。赞助若后续引入应独立展示。

自动化负责发现、查重、检查、生成和提醒；人工负责推荐、场景、实测、译文和图片判断。链接失败仅触发复核。停更不自动等于不可用。

每周处理推荐和重要错误，每月轮换复核一个板块。Issue 可只给来源与理由，PR 用于完整修改。1.0 已提供资源推荐、纠错和 PR 模板，以及内容校验、测试与构建的 CI 配置。

1.0 原创内容与代码沿用仓库现有 MIT 许可；第三方图片保留独立许可及署名，详见 [编辑规范](editorial-policy.zh-cn.md)。

## 当前展示原则

README 是可独立阅读的 awesome 清单，网站增强浏览。默认条目只写名称、原始链接与一句用途；必要时加收费标识，主题保留图片。长文用于工作流，不作为所有条目的准入门槛。读者文档不展示实测声明、核查状态和执行过程，图片署名与许可集中保留。
