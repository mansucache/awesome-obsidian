# From a project goal to next actions

## Goal

Connect outcomes, tasks and weekly reviews in a project note.

## Steps

- Create one project note with the desired result, deadline, scope and acceptance criteria. Describe an observable deliverable rather than an activity.
- List the next actions with clear verbs. Separate actionable tasks from ideas, reference material and items waiting on someone else.
- Choose a short list for the current week. Put fixed appointments in the calendar and keep task deadlines separate from planned work sessions.
- Record decisions and link the notes that explain them. Update the next action when work uncovers a dependency or changes the plan.
- Review weekly: compare progress with acceptance criteria, clear obsolete tasks and name the next step. At completion, archive the result and lessons together.

## Acceptance

- Every active project has a concrete next action.
- Completed work can be matched to the stated acceptance criteria.

## Optional extensions

Use [Tasks](tasks.md) to query actions across notes or [Kanban](kanban.md) to show stages; use [Periodic Notes](periodic-notes.md) for reviews.
