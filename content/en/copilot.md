# Copilot

[Copilot](https://github.com/logancyang/obsidian-copilot) — Chat with note context inside Obsidian, or connect agents such as Codex and Claude Code.

Useful for AI work within the note interface; agent backends run local processes and are desktop features, while mobile has a different feature set.

## Getting started

Begin with read-only questions over a small note set, then inspect references and proposed edits; model and account setup depend on the selected route.
